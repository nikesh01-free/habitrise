# HabitRise

HabitRise is a fully offline Flutter-based habit tracker and personal growth application focused on productivity, wellness, and daily self-improvement.

The app helps users build strong routines and track important lifestyle activities including habits, water intake, sleep, meals, focus sessions, gym schedules, mood tracking, step counting, and rewards — all stored locally on the device without requiring login, internet, or cloud sync.

## ✨ Features

- 📅 Daily Habit Tracking
- 💧 Water Intake Monitoring
- 💤 Sleep Tracking
- 🍽️ Meal Logging
- 🧠 Focus Timer & Deep Work Sessions
- 😊 Mood Tracking
- 👣 Step Counter Integration
- 🏋️ Gym Schedule Planner
- 📊 Analytics & Progress Insights
- 🔔 Local Reminder Notifications
- 🌙 Premium Dark Mode UI
- ⚡ Smooth Animations & Haptic Feedback
- 🔒 100% Offline & Privacy-Focused

## 🛠 Tech Stack

- Flutter
- Dart
- Riverpod
- Hive Local Database
- SharedPreferences
- Flutter Local Notifications
- FL Chart
- Table Calendar
- Permission Handler

## 📱 Platform

- Android
- iOS

## 🎯 Project Goal

HabitRise is designed to provide a clean, fast, and distraction-free self-improvement experience while keeping all user data fully private and stored locally on-device.
